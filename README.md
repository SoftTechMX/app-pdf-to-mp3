# PDF to MP3

Es una app de escritorio cuyo objetivos es extraer el texto del PDF y crear un audio en formato mp3 para personas con discapacidad visual o simplemente para personas que prefieren escuchar en lugar de leer.

## Dependencias

Para instalar las dependencias se usa venv, en VSCODE puedes seguir los siguientes pasos:

* Abre la paleta de comandos con (Cmd+Shift+P or Ctrl+Shift+P)
* Escrive env
* Selecciona la opcion que dice `Create Environment` Si ya tienes un environment Selecciona la opcion que dice `Activate Environment`

O Si porefieres usar la linea de comandos

* Abre la terminal
* ejecuta `python -m venv venv`
* ejecuta `pip install -r requirements.txt`
